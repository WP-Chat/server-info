# Privacy Policy

## Bot: Wapugh

**Effective date:** 2026-07-26
**Operator:** WP Chat team

Wapugh (“the Bot”) is a private Discord bot operated by the WP Chat team and used only in our server. This Privacy Policy explains what information the Bot accesses, how it is used, and how it is stored.

### 1. Information We Collect and Process
Wapugh processes information from **public text channels, public threads, and public forums** in our Discord server in order to detect repeated crossposted messages and spam.

The Bot may access and process the following information:
- Discord username
- Display name
- User ID
- Channel name
- Channel ID
- Message content
- Message timestamp
- Attachments
- Message metadata
- Roles

Wapugh does **not** process direct messages.

### 2. How We Use the Information
Wapugh uses message data to determine whether a user has posted the same or a substantially similar message in multiple channels. This allows the Bot to help prevent crossposting, spam, scams, and similar abusive behavior.

When a duplicate message is detected, the Bot may:
- delete the duplicate message,
- send a warning message to the user,
- send a private moderation log to the WP Chat team,
- request another moderation bot to issue a warning,
- and post a public reminder telling the user to read the rules.

### 3. Storage and Retention
Wapugh stores message data **in memory only**. It does not use a database or any persistent storage.

The Bot temporarily stores the following information:
- username
- content
- channel
- channel ID
- timestamp
- attachments

This stored data is automatically removed after **1 hour**. A cleanup process runs every **4 minutes** to delete expired data.

If the Bot restarts, all stored data is lost immediately.

### 4. Logging
Wapugh sends moderation logs to a private channel visible only to the WP Chat team. These logs contain the exact message content and related context, including:
- the original message,
- the duplicate message,
- the channel where it happened,
- the user who sent it,
- and the action taken.

These logs are used only for moderation and server safety.

### 5. Third-Party Services
Wapugh does not use analytics, advertising, or tracking services.

The Bot may interact with another moderation bot in a private channel to request warnings. That bot is operated separately and may have its own privacy policy.

### 6. Data Sharing
Wapugh does not sell, rent, or publicly share user data.

Information may be visible to:
- the WP Chat team,
- server moderators,
- the moderation bot used for warnings,
- and Discord, as part of normal platform operation.

### 7. Data Security
Wapugh is hosted in a private environment and is not exposed as a public-facing service.

The Bot does not provide a public dashboard or external user interface. Runtime data is temporary and stored only in memory, and it is discarded automatically or when the Bot restarts.

### 8. Children’s Privacy
Wapugh is intended for use in a Discord server that follows Discord’s age requirements. We do not knowingly collect personal information beyond what users voluntarily post in public channels.

### 9. Your Choices
Users can limit the information processed by Wapugh by not posting content in public channels monitored by the Bot.

If you have concerns about a message or a privacy matter, contact the WP Chat team or a server moderator.

### 10. Changes to This Policy
We may update this Privacy Policy from time to time. Any changes will take effect when the updated version is posted.

### 11. Contact
Wapugh is operated by the **WP Chat team**. For privacy concerns, please contact a moderator or the WP Chat team through the Discord server.
